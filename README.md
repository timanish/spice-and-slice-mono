# Spice & Slice Bazaar

Indo-Nepali food e-commerce store — [spiceandslice.shop](https://www.spiceandslice.shop)

## Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS + shadcn/ui
- Supabase (DB, Auth, Edge Functions, Storage)
- Clerk (Authentication)
- Stripe (Payments)
- Cloudflare Pages (Hosting)

## Development

```sh
bun install
bun dev
```
